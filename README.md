# UniTuTien-Welfare — Tiên Môn Phúc Lợi

![Paper](https://img.shields.io/badge/Paper-26.2%2B-blue)
![Java](https://img.shields.io/badge/Java-25-orange)
![Version](https://img.shields.io/badge/Version-1.0.0--TUTIEN-green)
![Server](https://img.shields.io/badge/Server-Th%C3%A1nh%20Linh%20Ti%C3%AAn%20V%E1%BB%B1c-gold)

Hệ thống phúc lợi giữ chân người chơi: Điểm Danh 7 Ngày, Chuỗi Hoạt Động 14 Ngày, Cửa Hàng Điểm Hoạt Động và Mốc Tiêu Phí (Vault + PlayerPoints).

## ✨ Tính Năng Nổi Bật

- Tự động theo dõi tiêu dùng tiền tệ Vault & PlayerPoints để mở khóa mốc quà.
- Liên kết trực tiếp với `UniTuTien-Path` (đã vá hook tự nhận diện) và `PlaceholderAPI` (`%uniwelfare_*%`).
